# K-DRIFT pilot homepage

D안의 이미지 중심 디자인을 선택한 파일럿 홈페이지입니다. 국문은 `PILOT 07`, 영문은 `ENGLISH EDITION · 20 OCT 2026`으로 표시합니다.

- 홈페이지: https://kasishongscience.github.io/kdrift/
- 영문판: https://kasishongscience.github.io/kdrift/en/
- `index.html`: 연구 소개·관측 성과·망원경·연구팀, 연구 심화·SIDM, 관측 기술, 성과 검증, G1 탐사 계획, 논문·영상·보도자료, 하단 S-DRIFT 소개
- `en/index.html`: 별도로 유지하는 영문 전체 번역본
- `language.css`: 국문 페이지의 한국어 / English 전환 링크와 반응형 헤더
- `team-hub-nav.css`: 양 언어 페이지의 Team Hub 링크와 헤더 배치
- `en/*.css` / `en/*.js`: 영문판 전용 스타일·동작. 루트 파일과 자동 동기화하지 않음
- `pilot.css`: 파일럿 레이아웃과 반응형 스타일
- `d.css` / `shared.css`: 기존 D안의 기본 스타일
- `shared.js`: 모바일 메뉴, 이미지 확대, 클릭 후 이메일 표시·숨기기
- `research.css` / `research.js`: 심화 본문·기술 표·성과·자료실과 논문 주제 필터
- `assets/`: 사용 이미지, KASI CI, 공개 홍보 PDF
- `a.html` / `d.html`: 기존 개별 시안 주소를 홈페이지로 연결

## 게시와 수정

2026-10-21: 국문·영문 헤더의 `Team Hub` 링크는 새 탭으로
`https://203.253.237.51/`를 연다. 접속이 허용된 기기에서는 SSH 터널 없이 이용한다.

이번 변경은 공통 탐색 메뉴에 한정하며 연구 본문과 영문판 날짜는 갱신하지 않는다.

GitHub Pages는 `main` 브랜치의 루트에서 배포합니다. 별도 설치나 빌드가 필요하지 않습니다. `.nojekyll`은 정적 파일을 그대로 게시하도록 합니다.

내용은 `index.html`, 기본 화면 구성은 `pilot.css`, 심화 영역은 `research.css`, 사진은 `assets/`에서 수정하고 커밋한 뒤 push합니다. `assets/`의 파일명과 HTML 참조를 함께 수정하세요. CSS/JS를 변경하면 해당 파일의 HTML 캐시 버전도 갱신합니다(현재 `research.css?v=pilot06`, `shared.js?v=pilot06`). 배포 후 Pages 최신 빌드의 커밋이 방금 올린 커밋과 일치하는지 확인합니다.

로컬 미리보기: 이 폴더에서 `python3 -m http.server 8765 --bind 127.0.0.1`을 실행하고 `http://127.0.0.1:8765/`를 엽니다.

현재 `noindex,nofollow`를 유지합니다. 검색 노출을 줄이기 위한 설정이며 접근 제한은 아닙니다. 전체 팀 명단은 아직 싣지 않았으며 연구책임자와 2024 워크숍 사진을 소개합니다.

## 국문·영문 독립 운영

국문은 루트 `index.html`, 영문은 `en/index.html`의 **독립된 정적 페이지**입니다. 상단의 한국어 / English 링크로 이동하며, 런타임 번역·공용 본문 데이터·자동 번역 빌드는 사용하지 않습니다.

- 일상적인 국문 수정은 루트 파일에만 반영합니다. `en/` 내용이나 영문판 날짜를 함께 갱신하지 않습니다.
- 사용자가 완성본의 영문 갱신을 요청했을 때에만, 그 시점의 국문을 검토·번역하여 `en/index.html`을 별도로 수정합니다. 영문판 날짜와 필요한 CSS/JS 캐시 버전을 그때 갱신합니다.
- 영문판의 CSS/JS는 자체 사본입니다. 국문 레이아웃이나 동작을 고쳐도 영문판에 자동 적용되지 않습니다. 공통 버그 수정이 필요하면 각 페이지를 명시적으로 수정하고 확인합니다.
- 이미지·공개 PDF만 `assets/`를 공유합니다. 국문 전용으로 이미지를 바꿀 때에는 새 파일명을 사용하여 이전 영문판이 참조하는 파일을 덮어쓰거나 삭제하지 않습니다.
- 첫 영문판은 2026-10-20의 국문 PILOT 06 전체 본문을 기준으로 합니다. 연구 소개, 캡션·대체 텍스트, 9편의 논문 요약, SIDM, S-DRIFT, 메뉴·필터·문의 기능을 번역했습니다. 논문 원제와 출처 URL은 유지합니다.
- 연결된 한국어 영상·PDF는 원본을 유지하고 링크에 `(Korean)`을 표시합니다. 상단 언어 링크, 문서의 `lang`, canonical과 hreflang을 각 페이지의 주소에 맞게 유지합니다.

## PILOT 02 — 연구 심화 확장 (2026-10-20)

첫 화면과 D안의 개요를 유지하고 연구팀 소개 뒤에 심화 내용을 추가했습니다. 연구 질문 6개, 광학·관측·보정 기술, G1 제원, 검증 성과 4개, SPIE 소개와 향후 방향을 담습니다. 자료실은 논문 7편과 영상 4편으로 확장했습니다. 2019–2026 이력은 제공된 2025.10.24 추가 자료와 2026.01.27 최종 보도자료를 기준으로 보완했습니다.

### 수치와 상태의 구분

- 패스파인더 표면밝기 한계: Byun et al. (2022), r 대역 약 28.5 mag arcsec⁻², **1σ / 10″ × 10″ / 2시간 / 0.3m 패스파인더**. G1의 실측 값으로 표기하지 않습니다.
- PSF FWHM 3.8 → 1.8 pixel: Lee et al. (2025)에 관한 **SPIE 제공 소개글**에서 확인한 패스파인더 개선 전·후 값. G1의 픽셀 스케일과 혼동하지 않습니다.
- G1 29–30 mag arcsec⁻²: Ko et al. (2025)의 **설계·탐사 목표**, r 대역 3σ / 10″ × 10″. 현재 달성 깊이나 완료된 탐사로 주장하지 않습니다.
- G1 입사동공 300 mm와 주경 500 mm를 구분했습니다. 검출기는 8120 × 8120, 픽셀 각크기 1.96″입니다.
- 롤링 디더링: Byun et al. (2025)의 **모의관측** 비교 결과로 소개합니다. 모식도는 원리를 설명하기 위해 새로 그린 SVG이며 실제 관측 이동량·회전각을 재현하지 않습니다.
- 장기 우주망원경 방향은 제공된 인터뷰·기획 자료의 연구 구상입니다. 개발 완료·발사 확정으로 표현하지 않습니다.

## PILOT 03 — 문구 개정 (2026-10-20)

연구자가 작성하는 과학 설명을 기준으로 홈페이지 제목, 본문, 관측 영상 설명, 논문·영상 요약, 메타데이터를 개정했다. 비유와 수사의문문을 연구 대상·분석 방법을 명시하는 표현으로 바꾸고, 본문은 “~한다/~이다”체로 통일했다. 예를 들어 첫 제목은 “초극미광 관측과 은하 진화 연구”, 심화 본문의 질문형 제목은 “은하 병합과 항성 질량 증가” 등의 연구 주제명으로 수정했다. 외부 논문·기사·영상의 원제는 그대로 표기한다.

관측 수치와 측정 조건, 출처 링크, 이미지, 페이지 구성은 유지했다. 새로운 SIDM 내용은 추가하지 않았다. 사용자가 archive에 관련 자료를 제공한 뒤 연구와 게재안을 다시 검토한다.

### 이후 문구 작성 기준

- 구체적인 관측 대상, 측정량, 방법, 결과를 서술한다.
- 은유, 감탄, 질문형 홍보 문구를 사용하지 않는다. 제목에는 연구 주제나 기술명을 쓴다.
- 관측 결과, 모의실험 결과, 설계 목표, 장기 구상을 구분한다. 수치에는 기기·파장대·검출 기준을 유지한다.
- 외부 자료의 제목은 출처의 원문을 유지하고, 홈페이지에서 작성하는 요약은 같은 평서문 문체를 적용한다.

### 확인 기록

데스크톱 1280px와 모바일 390px·320px에서 문구 넘침을 점검했다. 모바일 메뉴와 연구 심화 이동을 확인했다. HTML의 로컬 참조 44개를 점검했으며 기존 링크·이미지 참조 및 섹션 ID 28개는 변경되지 않았다. CSS·JavaScript는 수정하지 않았다.

## PILOT 04 — 문체 조정 (2026-10-20)

과학적 설명과 구체적인 제목은 유지하고, 본문과 캡션을 “~합니다/~입니다”체로 조정했다. “표본을 확보하고”, “비교를 수행한다” 같은 딱딱한 표현은 “초확산은하를 찾아”, “비교합니다” 등으로 풀어 썼다. 현재 문체 기준은 정확한 과학 설명에 자연스러운 존댓말을 사용하는 것이다. 비유와 과장된 홍보 문구는 사용하지 않는다.

SIDM 및 S-DRIFT 관련 새 내용은 이번 문체 수정에 포함하지 않았다. 추가된 S-DRIFT 기획연구 자료를 검토한 뒤 게재할 내용과 위치를 제안하고 사용자 확인 후 반영한다.

데스크톱 1280px와 모바일 320px에서 문구 배치와 가로 넘침을 확인했다. 링크·이미지 참조·섹션 ID는 이전 버전과 같으며 로컬 참조 파일이 존재하는지 점검했다.

## PILOT 05 — 암흑물질·SIDM 연구와 S-DRIFT 소개 (2026-10-20)

- `#dark-matter`: 초극미광 관측과 암흑물질의 관계, SIDM과 표준 CDM의 차이, 왜소·초확산은하 / 항성 헤일로·조석 구조 / 은하단내광의 관측량과 연구 방향.
