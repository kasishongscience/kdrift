# K-DRIFT website design preview

K-DRIFT 홈페이지의 A안과 D안을 비교하는 구성원 의견 수렴용 정적 사이트입니다. 공개 게시용 시안이며 최종 공식 홈페이지가 아닙니다.

- `index.html`: 시안 선택
- `a.html` / `a.css`: 간결한 연구 소개형
- `d.html` / `d.css`: 이미지 중심형
- `shared.css` / `shared.js`: 공통 스타일과 메뉴·이미지 확대
- `assets/`: 홈페이지에 쓰인 사진과 공개 홍보자료

## 게시

GitHub Pages의 소스를 `main` 브랜치, `/(root)`로 설정합니다. 별도 빌드 도구는 필요하지 않습니다. `.nojekyll`은 정적 파일을 그대로 게시하도록 합니다.

## 수정

문구는 해당 HTML에서, 사진은 `assets/`에서 수정하고 `main`에 커밋하면 같은 주소에 반영됩니다. 이미지 파일명을 바꾸면 HTML의 경로도 함께 수정합니다. 세부적인 팀 명단과 논문 목록은 확정 후 추가할 수 있습니다.

관측 성과는 2026.01.27 우주항공청·한국천문연구원 보도자료를 기준으로 소개합니다. 사진·관측 영상의 출처는 페이지에 표기했습니다. 해당 자료의 권리는 원 권리자에게 있습니다.
